# My 3-Day Home Workout Routine

A classic and effective 3-day split routine designed for home with **2 Dumbbells + 1 Barbell**.

### Equipment
*   🏋️ 2 Dumbbells
*   🏋️ 1 Barbell

### Schedule
*   **Day 1:** Push (Chest, Triceps, Shoulders)
*   **Day 2:** Pull (Back, Biceps)
*   **Day 3:** Legs
*   **Day 4:** Rest
*   **Repeat.** (This gives you a flexible schedule, working out 3-4 times a week).

## **Important Notes**

*   **Warm-Up:** Follow the detailed Warm-Up Routine above before starting.
*   **Form Over Weight:** Focus on perfect technique before increasing the weight.
*   **Progressive Overload:** Try to add a little more weight or do one more rep each week.
*   **Cool Down:** Follow the detailed Cool-Down Routine above after each session.
